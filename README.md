# CursorGrid Homebrew tap

Move and click the pointer from the keyboard with a grid.

```sh
brew install --cask cursorgrid/tap/cursorgrid
```

Or download the DMG from the [latest release](https://github.com/cursorgrid/homebrew-tap/releases/latest).

Needs macOS 14 or later on an Apple silicon Mac. On first launch, allow CursorGrid in
System Settings, Privacy & Security, Accessibility.
